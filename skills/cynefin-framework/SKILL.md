# Cynefin

Определи, в каком домене ситуация, и запиши подход этого домена. Слот промпта — одна ситуация. Пустая ситуация и несколько несвязанных ситуаций слотом не являются.

Пять доменов. Домен назначается по совпадению картины ситуации с его описанием. В признаки попадают те черты описания, которые ситуация подтверждает. У каждого признака опора.

- Простой (clear, его же называют obvious и simple). Ситуация знакомая и ясно задана, причина и следствие ясны, ситуация устойчива. Это область «известного известного». Решение обычно видно и почти не требует специального знания. Часто это устоявшийся процесс. Подход sense–categorise–respond: понять ситуацию, отнести к известному классу, ответить известной практикой.
- Запутанный (complicated). Верных ответов может быть несколько, и они не видны сразу. Вопросы ясны, ответ требует работы. Это область «известного неизвестного». Нужен тот, кто знает предмет: он оценивает ситуацию, рассматривает варианты и выбирает ход. Подход sense–analyze–respond: понять ситуацию, разобрать, ответить.
- Сложный (complex). Область «неизвестного неизвестного». Разбором ситуацию не понять: о ней ещё мало известно, и неясно, на какой вопрос отвечать. Подход: сначала эксперимент, чтобы узнать задачу, затем понять, с чем имеем дело, и ответить. Цель — узнать достаточно, чтобы ситуация перешла в запутанный домен.
- Хаотичный (chaotic). Ситуация не под контролем, причина и следствие неясны. Подход act–sense–respond: сначала действие, чтобы вернуть устойчивость и удержать ситуацию, затем разбор и наведение порядка, чтобы перевести её в сложный домен. В этом домене легче принимают новый ход.
- Замешательство (disorder). Неясно, в каком домене ситуация. Задача — быстро определить домен. Для этого ситуацию делят на части и каждой части назначают свой домен.

Четыре вопроса помогают собрать картину. Домен выбирают признаки домена. Вопросы только собирают картину для этого выбора.

## Куда писать

`.rdd/cynefin-framework/<ситуация>.md`

Один файл на одну ситуацию. Имя файла — kebab-case ситуации: нижний регистр, слова через дефис, латиница (`Сбой оплаты в час пик` → `sboy-oplaty-v-chas-pik.md`). Каталог создавай вместе с первым файлом. Повторный запуск для той же ситуации обновляет этот файл. Если в файле стоит `> пробел:`, продолжи с этого места. Сначала прочитай каталог: та же ситуация под другим написанием имени — обновляй её, второй файл не создавай. В файле уже другая ситуация — задай один вопрос и остановись. Каталог `.rdd/` коммитится вместе с репозиторием.

Язык файла — язык, на котором названа ситуация. Имена доменов оставь как в формате.

## Ход

1. Возьми ситуацию из сообщения пользователя. Её нет — задай один вопрос, какую ситуацию разбираем, и остановись до ответа. Названо несколько несвязанных ситуаций — задай один вопрос, какую берём, и остановись. Готово, когда ситуация сформулирована одним предложением и имя файла в kebab-case.

2. Прочитай репозиторий и `.rdd/` на опору этой ситуации. Готово, когда каждый заимствованный факт указан путём к файлу либо в репозитории опоры не нашлось.

3. Ответь на вопросы по порядку. Ответ берётся из сообщения или файла и идёт с опорой. Опоры на вопрос нет — на нём `> пробел:`, запиши файл до этого вопроса, задай этот вопрос пользователю и остановись. Домен в этот запуск не назначай. Оставшиеся вопросы в файл не входят.

   Вопросы по порядку:

   - Известна ли причина ситуации?
   - Ситуация под контролем?
   - Насколько ситуация известна?
   - Нужно ли для решения знание специалиста?

   Готово, когда у каждого записанного вопроса есть опора, либо ход остановился на одном вопросе.

4. Назначь один домен по описаниям выше. В «Признаках» перечисли те признаки выбранного домена, которые подтверждены ответами, и у каждого опора. Картина сходится к одному домену — он и есть. Картина сходится к нескольким доменам, и по источникам неясно, где стоим, — домен «замешательство». Ни один домен не подтверждён, потому что на вопрос не было опоры, — это пробел шага 3, а не замешательство. Готово, когда назван один домен и у каждого записанного признака есть опора.

5. Запиши подход этого домена и конкретный ход из источников.

   Простой: известная практика, которой отвечают. Практики в источниках нет — на ходе `> пробел:`.

   Запутанный: вариант, который рассматривает знающий предмет. Вариантов в источниках нет — на ходе `> пробел:`.

   Сложный: эксперимент, с которого начинают, чтобы узнать задачу. Какой эксперимент ставить, бери из источников. Эксперимента в источниках нет — на ходе `> пробел:`. Рядом одна фраза: эксперимент нужен, чтобы ситуация перешла в запутанный домен.

   Хаотичный: действие, которое возвращает устойчивость и удерживает ситуацию. Действия в источниках нет — на ходе `> пробел:`. Рядом одна фраза: после удержания ситуацию переводят в сложный домен. Новый ход запиши рядом, только если источник его уже назвал.

   Замешательство: разложи ситуацию на части из источников и каждой назначь домен по шагу 4, с подходом этой части. Частей в источниках нет — на частях `> пробел:`. Часть, которой признаки не подтверждают домен, — на ней `> пробел:`. В этом запуске один разрез.

   Хотя бы одна такая строка с пробелом — запиши файл, задай один вопрос по первой из них и остановись. Готово, когда подход домена записан, а конкретный ход либо опирается на источник, либо ход остановился на одном вопросе.

6. Запиши файл в формате ниже. Готово, когда файл лежит по пути из первого раздела, а ответ называет этот путь, домен и остановился ли ход на пробеле.

## Формат файла

Один markdown-файл:

- заголовок `#` с ситуацией;
- строка `Ситуация:` — одно предложение;
- «Вопросы» — четыре вопроса по порядку; у записанного ответа опора; на месте остановки `> пробел:`;
- строка `Домен:` — одно из: простой, запутанный, сложный, хаотичный, замешательство; вопросов ещё нет — `> пробел:`;
- «Признаки» — подтверждённые признаки этого домена, у каждого опора;
- строка `Подход:` — подход этого домена;
- строка `Ход:` — конкретный ход из источников либо `> пробел:`;
- «Части» — только для домена «замешательство»: часть, её домен, признаки с опорой, подход. Частей нет — `> пробел:`.

Дырка в знаниях — цитата `> пробел:`.

## Держать

- Домен называется по описанию домена, признаки подтверждены ответами.
- Простой отвечает известной практикой. Запутанный разбирает тот, кто знает предмет. Сложный начинается с эксперимента и ведёт к запутанному. Хаотичный начинается с удержания и ведёт к сложному.
- Новый ход в хаотичном домене берётся из источника.
- Замешательство делит ситуацию на части и назначает домен каждой части.
- В одном файле одна ситуация.
