# Мышление второго порядка

Посмотри, к чему решение приводит сразу, и для каждого такого следствия спроси «и что потом?». Слот промпта — одно решение. Пустое решение и несколько несвязанных решений слотом не являются.

У приёма два хода. Основной — порядки: ближайшее следствие, затем «и что потом?», и так дальше, сколько практично. Другой ход — те же следствия на трёх горизонтах: 10 минут, 10 месяцев, 10 лет, то есть короткий, средний и долгий срок. Горизонты бери, когда пользователь просит смотреть по времени. Оба хода в одном запуске — когда пользователь просит оба.

## Куда писать

`.rdd/second-order-thinking/<решение>.md`

Один файл на одно решение. Имя файла — kebab-case решения: нижний регистр, слова через дефис, латиница (`Смена тарифа` → `smena-tarifa.md`). Каталог создавай вместе с первым файлом. Повторный запуск для того же решения обновляет этот файл. Если в файле стоит `> пробел:`, продолжи с этого места. Сначала прочитай каталог: то же решение под другим написанием имени — обновляй его, второй файл не создавай. В файле уже другое решение — задай один вопрос и остановись. Каталог `.rdd/` коммитится вместе с репозиторием.

Язык файла — язык, на котором названо решение. Заголовки блоков оставь как в формате.

## Ход

1. Возьми решение из сообщения пользователя. Его нет — задай один вопрос, какое решение разбираем, и остановись до ответа. Названо несколько несвязанных решений — задай один вопрос, какое берём, и остановись. Готово, когда решение сформулировано одним предложением и имя файла в kebab-case.

2. Прочитай репозиторий и `.rdd/` на опору следствий этого решения. Готово, когда каждый заимствованный факт указан путём к файлу либо в репозитории опоры не нашлось.

3. Пользователь просит смотреть по времени — запиши следствия на горизонтах 10 минут, 10 месяцев и 10 лет. Следствие берётся из сообщения или файла и идёт с опорой. На горизонте следствия в источниках нет — на этом горизонте `> пробел:`. Этот запуск только про горизонты, и хотя бы один из них с пробелом — запиши файл до этого места, задай один вопрос по первому пустому горизонту и остановись. Оба хода запрошены — пробел горизонта запиши и переходи к порядкам. Порядки в этот запуск не входят, если пользователь просил только горизонты: шаги 4 и 5 тогда пропусти. Готово, когда у каждого из трёх горизонтов есть следствие с опорой или пробел, и ход назван.

4. На ходе порядков выпиши ближайшие следствия решения — первый порядок. Следствие берётся из сообщения или файла и идёт с опорой. Ближайшего следствия в источниках нет — поставь `> пробел:`, запиши файл до этого места, задай один вопрос, какое ближайшее следствие у этого решения, и остановись. Следующие порядки в этот запуск не пиши. Готово, когда каждый записанный пункт первого порядка имеет опору, либо ход остановился на пробеле.

5. Для каждого следствия первого порядка ответь «и что потом?» — это второй порядок. Второй порядок есть в источниках — запиши его с опорой. Второго порядка в источниках нет — на этом следствии `> пробел:`, запиши файл до этого места, задай один вопрос и остановись. Порядки после места остановки в файл не входят. Третий и следующие порядки пиши, пока очередное «и что потом?» есть в источниках. Очередного порядка в источниках нет, а второй уже записан — ветка на этом кончается. Число порядков заранее не задано. Готово, когда у каждого следствия первого порядка есть второй порядок с опорой либо запуск остановился на одном вопросе, и каждый дальнейший записанный порядок имеет опору.

6. Запиши файл в формате ниже. В файле только тот ход, который шёл в этом запуске. В файле остался `> пробел:` и вопрос на этом запуске ещё не задан — в ответе один вопрос по первому такому месту. Готово, когда файл лежит по пути из первого раздела, а ответ называет этот путь, какой ход записан и остановилась ли запись на пробеле.

## Формат файла

Один markdown-файл:

- заголовок `#` с решением;
- строка `Решение:` — одно предложение;
- строка `Ход:` — `порядки`, `горизонты` или `оба`;
- «Первый порядок» — на ходе порядков: ближайшие следствия, у каждого опора;
- «И что потом» — на ходе порядков: по каждому следствию первого порядка цепочка следующих порядков; у звена опора; обрыв ветки до второго порядка — `> пробел:`;
- «Горизонты» — на ходе по времени: `10 минут`, `10 месяцев`, `10 лет`; у каждого опора или `> пробел:`.

Блок хода, которого в этом запуске не было, в файл не входит. Дырка в знаниях — цитата `> пробел:`.

## Держать

- Первый порядок — ближайшее следствие решения. Следующий порядок отвечает на «и что потом?» по предыдущему.
- Второй порядок есть у каждого записанного ближайшего следствия. Дальше ветка идёт, пока следующее следствие есть в источниках.
- Горизонты 10 минут, 10 месяцев и 10 лет — другой ход той же техники.
- В одном файле одно решение.
