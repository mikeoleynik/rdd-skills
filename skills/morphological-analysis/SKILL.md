# Morphological Analysis

Собери морфологический ящик (Morphological Box) одной задачи: оси параметров, значения и поле сочетаний. Слот промпта — одна задача. Исходная идея, если она названа, помечает одну клетку ящика. Несколько несвязанных задач слотом не являются.

Результат — файл, в котором видны параметры, значения, число сочетаний и либо одно сочетание под названную цель, либо пробел на выборе.

## Куда писать

`.rdd/morphological-analysis/<задача>.md`

Один файл на одну задачу. Имя файла — kebab-case задачи: нижний регистр, слова через дефис, латиница (`Срок поставки заказа` → `srok-postavki-zakaza.md`). Каталог создавай вместе с первым файлом. Повторный запуск для той же задачи обновляет этот файл. Сначала прочитай каталог: та же задача под другим написанием имени — обновляй его, второй файл не создавай. В файле уже другая задача — задай один вопрос и остановись. Каталог `.rdd/` коммитится вместе с репозиторием.

Язык файла — язык, на котором названа задача. Заголовки блоков оставь как в формате.

## Ход

1. Возьми задачу из сообщения пользователя. Её нет — задай один вопрос и остановись до ответа. В сообщении только готовое решение — слот это задача, которую решение закрывает; задай один вопрос, какую задачу разбираем, и остановись. Названо несколько несвязанных задач — задай один вопрос, какую берём, и остановись. Готово, когда есть одна задача и имя файла в kebab-case.
2. Прочитай репозиторий и `.rdd/` на опору задачи: ограничения, уже названные свойства, уже записанные ящики. Готово, когда каждый заимствованный факт указан путём к файлу либо в репозитории опоры не нашлось.
3. Назови параметры. Параметр — ось решения: свойство, которое может принять больше одного значения и не повторяет другую ось. Параметры бери из сообщения и из опоры. Ось, которой в источниках нет, помечай `вариант`: это предлагаемое измерение задачи, не факт об устройстве системы. Меньше двух осей — задай один вопрос, какое свойство ещё меняется, и остановись. Готово, когда осей две или больше и каждая принимает несколько состояний.
4. По каждой оси выпиши значения: состояния, которые на этой оси друг друга исключают. Значение из сообщения или файла идёт с опорой. Значение, которого в источниках нет, помечай `вариант`. Ось с одним состоянием — задай один вопрос, какое ещё состояние у неё бывает, и остановись. Готово, когда у каждой оси два или больше взаимоисключающих значения.
5. Собери ящик. Сочетание — ровно одно значение с каждой оси. Запиши число сочетаний произведением чисел значений. Исходную идею посади на её клетку; значения идеи, которых на осях ещё нет, добавь на свои оси с опорой. Сочетание, которое противоречит ограничению из сообщения или репозитория, запиши как исключённое и укажи опору ограничения. Ограничений в источниках нет — одна строка: известных противоречий нет. Готово, когда таблица ящика полна, число сочетаний посчитано, исходная идея либо сидит на клетке, либо её не было, и каждое исключение опирается на ограничение.
6. Выбор — одно сочетание, которое отвечает цели из сообщения пользователя. Цели нет — в «Выборе» поставь `> пробел:`, задай один вопрос, по какой цели отбирать, и остановись. Под цель подходят несколько сочетаний — запиши их и поставь на единственном выборе `> пробел:`, задай один вопрос, чем их различить, и остановись. Готово, когда выбрано одно сочетание и рядом названа цель, либо выбор остался пробелом.
7. Запиши файл в формате ниже, включая остановку на пробеле: разделы после пробела не заполняй. Готово, когда файл лежит по пути из первого раздела, а ответ называет этот путь, число сочетаний и остановился ли выбор на пробеле.

## Формат файла

Один markdown-файл:

- заголовок `#` с задачей;
- строка `Исходная идея:` — идея, с которой пришли, или `нет`;
- «Параметры» — ось, затем её значения; у значения опора или пометка `вариант`; у оси без источника пометка `вариант`;
- «Ящик» — таблица «параметр / значения» и строка с числом сочетаний;
- «Исключения» — сочетания, которые ломает известное ограничение, со строкой `Опора`; известных противоречий нет — одна строка об этом;
- «Выбор» — цель и одно сочетание, либо `> пробел:`.

Дырка в знаниях — цитата `> пробел:`.

## Держать

- Параметр — ось. Значение — одно состояние этой оси. Сочетание берёт по одному состоянию с каждой оси.
- Исходная идея занимает одну клетку. Остальное поле остаётся в таблице.
- `вариант` называет возможную ось или возможное состояние. Факт о системе стоит там, где есть опора.
- Исключение ссылается на ограничение из сообщения или репозитория.
- Выбор ссылается на цель из сообщения пользователя.
- В одном запуске один вопрос.
